# fromscratch

A React application wired up **without** Create React App — Webpack and Babel configured
by hand.

The point of the exercise: understand what CRA actually does. Entry points, loaders for
JS and CSS, asset handling, the HTML plugin, and the Babel presets that make JSX and
modern syntax work.

## Stack

React, Webpack, Babel (`@babel/preset-env`, `@babel/preset-react`), css-loader,
file-loader, html-webpack-plugin.

## Running it

```bash
npm install
npm start
```
